# 🎬 Netflix Movies and TV Shows Data Analysis

An exploratory data analysis (EDA) project on Netflix's catalog to uncover key insights regarding content types, global content distribution, and release trends.

## 📊 Key Highlights
- **Content Distribution:** Visual comparison between Movies and TV Shows.
- **Top Countries:** Analysis of the top countries producing Netflix content.
- **Release Trends:** Trend of content release years over time.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
